# Harness Activation Matrix

| Task type | Required gates | Optional gates | Skipped by default | Approval-gated actions |
|---|---|---|---|---|
| Small local edit | Read target, implement directly, smallest claim-matched check | TDD only on explicit/red-green trigger | OpenSpec, review pipeline, research, memory writeback | Exact risky operation only |
| Unclear idea | IDEATE primary loop | one official/prior-art capability for a named gap | implementation, parallelism ceremony, automatic research chain | Material decision or exact risky operation |
| Spec or plan work | DEFINE/ordinary plan owner, dependency-ready artifacts, needed material questions | one source capability for an exact gap | automatic stress-test/review/research fan-out | Starting formal BUILD before final test-plan acceptance |
| Bounded implementation | ordinary/BUILD primary owner, accepted scope, smallest claim-matched check | one concrete auxiliary capability | automatic TDD/review/security/full suite | Scope expansion or exact risky operation |
| User-requested packaging | target/platform, claim-matched checks, package evidence, at most one targeted repair/recheck | affected artifact smoke check | packaging as a substitute for tests | signing, notarization, certificates, dependency/lockfile changes, external publishing |
| Ship/closeout | fresh intent, current implementation evidence, direct affected-claim inspection | one review/packaging/release capability for a concrete gap | automatic review/repair matrix, new feature work | Archive/publish/push/merge/release |
| Harness change | harness change report, component map, verification trigger | security/review audit | silent apply | ROSE/command/skill/subagent/memory/install edits |
| Security/trust boundary | exact material/security gate plus affected evidence | one bounded security capability when selected | automatic broad audit | Weakening safety policy |
| Historical umbrella implementation package | complete assigned behavior, dependency/file ownership, lightweight savepoint with scope/files/unresolved/next | focused feedback only when a claim/risk needs it | mandatory independent package-local quality gate | Scope expansion or high-risk/pre-action operation |
| Canonical completion inspection (historical umbrella name: Package 12) | direct final diff and affected-link inspection, smallest relevant fresh check | one auxiliary capability for a concrete gap, one targeted repair/recheck | automatic review swarm, full command matrix by default | Graphify execution, publish/push/archive, destructive action |

## Gate Intent

- Prevent over-triggering for simple, local work.
- Prevent under-triggering for harness, memory, security, subagent, install, or completion-claim changes.
- Keep parallelism, research, TDD, review, and security optional and gap-driven without adding new public commands.
- Package numbering is historical to the umbrella change; the current generic rule is a lightweight savepoint plus one direct final claim-matched inspection.
