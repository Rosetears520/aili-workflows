## 执行约定（冻结）

- 每个编号的「提示」是用户输入；不把「判断」拼入提示。引用其他编号时，按明确引用原样展开，不重新生成材料。子用例各自执行，只有 T07、T13、T08 明确要求连续步骤。
- PPT 计划样例共同前缀 P：`只在回复中给中文逐页 Markdown 内容计划，不创建文件，不编译或渲染。每页使用 ## Slide NN:、稳定 slide-id、一个 ### 1. Layout 和一个 ### 2. Content。来源仅限本提示材料。`
- T01、T02、T03 使用 P 加各自提示；其他编号只用各自提示。凡多子用例不得只选其中一项算整例完成。
- P4 复用这些字节、子用例顺序和基线中可获得的模型/设置；工具和 Skill 版本差异单列。输入如需修订另记版本，不能覆盖 v1 后直接称同输入对比。
- 记录原始输出、实际路由/工具轨迹、事实核对及未验证项。文本判断不代替工具执行、字体、模板或视觉证据。静态检查不代替实际路由。
- T04 合同是计划层合成输入，不是真实模板容量测量。T07/T08/T16 的受限运行需要真实能力控制或实际失败证据；不能用模型扮演失败冒充执行。
- 所有生成工作区仅可由获授权的 P4 放在本 change 的 verification 内；本文件不新增写权限、安装、网络或审批授权。缺工具/确认就记录 blocked / Unverified。
