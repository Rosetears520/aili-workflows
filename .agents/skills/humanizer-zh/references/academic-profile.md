# 中文论文语体

处理论文正文时读取本文件。自然的学术表达应让读者看出材料、方法与推断的关系，不是把论文改成随口聊天。

## 硬信息与范围

保留方法名、模型名、变量/构念、假设编号、题项编号、样本来源、统计值、单位、年份、图表编号与引用。统计意义的“显著”、方向、区间、不等号和相关/因果关系不能为降调而消失。

不把“复游率”替换为“重游意愿”，不把“满意度”简化为“喜欢”，不靠高级同义词让一个变量有多个名称。术语密集时改它周围的句子，而不是改术语定义。

默认处理正文自然段，跳过章节标题、表格/表题、图题图注、参考文献、问卷选项与独立编号，并说明跳过范围。用户明确要改非正文时，先圈定允许调整的文字；不改表格数值、编号、引用结构或扩写成新研究发现。遇到事实核查或数据纠错请求交回 ROSE，不能冒充已查证。

## 按段落真正的工作改写

| 段落用途 | 改写重点 | 避免 |
|---|---|---|
| 文献综述 | 保留谁研究了什么、方法/材料、发现及已有引用；按已有研究关系组织 | 没有依据地称“奠定范式”，补假文献，把不同来源结论拼成一个共识 |
| 理论/定义 | 保留准确术语与定义，用普通话解释原文已给的关系和用途 | 将构念替换为不等义日常词，编理论来源 |
| 方法 | 讲清实际给出的对象、步骤、处理和用途；需要时保留长句 | 补造发放、筛选、访谈、实验或伦理审批过程 |
| 结果 | 数值与其直接含义相邻，保留比较基线和样本范围 | 从一个比例推导全场景优势，把未显著结果写成有效结论 |
| 案例概况 | 保留地点、对象及与研究相关的原有信息 | 增添宣传语、资质或实地观察细节 |
| 建议/讨论 | 将原文发现和对应动作接起来，保留条件及推断层级 | 空喊优化提升，或把建议写成已验证成效 |

这些是判断方向，不是每段必须填完的模板。原材料没有“局限”“用途”时不硬补；若结论确实越界，只用原材料可支持的边界收回。

## 学术语气不是统一弱化

有证据的确定事实照写。适当的“可能”“主要”等只用于原有推断或有依据的限缩，不每句加“较为”“一定程度上”。原文的正式第一人称如“我们采用”可以保留，不默认引入个人情绪、玩笑或作者经历。

减少正文中无用的加粗、装饰性项目符号和助手开场，保留必要数学符号、专业括号、引用及原结构。不要为了低格式痕迹删除统计标记。

## 成稿与说明

默认每个正文段有原文、修改后和说明。说明只解释实际改动、保留项及未核实问题；成稿本身不出现“此处建议补充”“待用户提供数据”。确实无需修改时保留原文并注明，不以漏段代替判断。

判断改得是否合适：还是同一段研究材料、同一论文位置和同一论证力度；更清楚但不变成新闻、政策口号、邮件或聊天。若自然度与学术准确性无法兼顾，保留准确性并说明限制。
