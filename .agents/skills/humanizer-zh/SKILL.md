# 中文自然写作

让原作者的意思更容易读懂，而不是伪装作者身份。先保住事实、术语和立场，再改表达关系。自然不等于随意；原文已经合适时可以不改。

## 入口与能力

- 有已有中文且明确要求改写：按下文选论文或通用语体。
- 只有概念问题、没有待改原文：交回 ROSE 直接解释；不要制造改写任务。
- 需要创建/编辑 PPTX、DOCX 等文件：文件仍归对应 artifact owner。本 Skill 只提供文本，不能替代文件验证。
- 英文、从零论文、事实核查等近邻任务交回 ROSE；不强行翻译、补造研究或启动外部检索。
- 需要 `repo.read` 读取必需方法资源及授权的本地原文；缺失时返回 `blocked`，明确未读到的资源，不虚构已处理。`repo.write` 可选；不可写时 `SKIP` 文件保存，获准的聊天输出仍可交付。粘贴文本不要求额外建文件。
- 本 Skill 不调用检测器，不上传原文，不依赖外部同名 Skill 或个人目录。文件写入须有范围与落点；ROSE 决定路由、审批及最终验收，Skill 不递归、不委派。

| 条件 | 资源 |

简短通用段落可按主文执行；应读资源不可用时不要靠猜测宣称完整执行。

## 执行

### 1. 确定语体和覆盖范围

能从原文识别时直接采用最窄语体：论文保持正式平实，邮件/报告/说明保持原说话者、对象、礼貌程度和用途。不默认加入第一人称，也不删除原作者合理使用的第一人称。只有体裁不明且不同选择会实质改变交付时，问一个用途/读者问题。

全文或连续正文按原顺序逐段覆盖；检测报告只改能对应原文的标记段落。只有总分或定位不清时索取原段/对应关系，不猜写。论文默认跳过标题、表格、图注、参考文献、问卷选项等非正文并说明；通用文稿不默认排除用户要改的标题和列表。

完成条件：知道要处理哪些段、哪些不动及输出格式，不把局部需求扩大为全文。

### 2. 先保护意思

保留数字、单位、年份、样本量、模型、变量、术语、引用、表图编号、专名、否定、比较基线、范围、因果/相关关系及作者立场。引文内容按原引用边界保留；只调整引用外围表达。

不确定术语时保留原词。事实矛盾时不偷偷改数或编理由，在正文外说明未核实。结论有依据时不能机械弱化，例如统计意义的“显著”不可随意删掉。

遇到真实或明确标记未脱敏的凭据/个人敏感信息，先要求脱敏，不在“原文/修改后”中复述敏感值；无需查找或上传其他数据。

完成条件：改写有清楚的语义边界，而非为了顺口改变研究对象或结论。

### 3. 找出具体问题再改

检查是否有空泛名词串、冗余连接、无来源权威、无依据拔高、助手残留、机械对称或同义词造成的概念漂移。单个“基于”“机制”不是禁词。

把已有对象、动作、关系和用途说清楚；能删重复就删，确有关系才留连接。句长随内容变化，不按比例随机拆句，不强凑三项，不每段都升华。必要术语可以重复，不为了“丰富词汇”换构念。

存在问题的段落至少改善一项结构/关系/判断/语体问题，不只把“本文”换成“本研究”。本来准确简洁的段落可以原样保留并说明原因。

完成条件：读者更容易理解原意，且没有新增数据、经历、访谈、引用、过程或承诺。

### 4. 输出并核对

默认按原段落顺序给“原文 / 修改后 / 说明”。说明点出实际变化和关键保留项；不要每段复制同一条空泛说明。用户指定“只要成稿”或其他格式时优先遵守，必要的事实疑点放正文之外。

“修改后”是可直接使用的文字，不混入“建议补充”“待核实后再写”等编辑指令。论文正文减少无用装饰；PPT、邮件和报告中的有效标题、列表、加粗无需为去 AI 腔而一律删除。

一次无法覆盖全部时在段落边界停止，说明本次已处理与剩余范围；明确继续时从下一未处理段接续。不要静默漏段或说全文已完成，也不要自动启动续写循环。

完成条件：逐段检查硬信息、判断力度、语体、覆盖与格式；只对实际处理范围给出完成结论。

## 检测与真实性边界

可以处理“降 AIGC”背后的表达需求，但不能保证过检、预测百分比、伪造检测结果或证明作者是人/AI。若用户要求保证，简短说明只能改善表达，再处理可做的部分。不故意加错字、语病或编个人细节来骗检测；不以“人味”代替准确性。

## 停止状态

- `complete`：约定范围已改写/合理保留并核对；不代表检测通过。
- `need-user`：用途关键不明、报告无法定位，或需要先脱敏。
- `need-evidence`：缺原文或必要上下文，无法忠实改写。
- `blocked`：必需读取能力/权限缺失；说清具体受阻项。
- `material-delta`：请求扩展到其他产物、事实研究或新增服务，由 ROSE 决定。
- `Unverified`：事实真伪或实际运行效果没有证据；不能以流畅表达掩盖。
